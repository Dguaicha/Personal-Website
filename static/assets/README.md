# Portfolio assets

Add files to these folders and reference them from `content/portfolio.py`.

- `images/profile/` — professional portrait, e.g. `david-guaicha.jpg`
- `images/education/` — school and university logos
- `images/projects/` — project screenshots
- `documents/certificates/` — public certificate PDFs
- `documents/transcripts/` — public transcript PDFs
- `documents/resume/` — CV/resume PDF

Use lower-case, hyphenated filenames. Keep only documents you are happy to make public here. The site has intentional placeholders until files are added.
